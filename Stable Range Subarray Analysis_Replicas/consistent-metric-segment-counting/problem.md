## Title
Consistent Metric Segment Counting

## Slug
consistent-metric-segment-counting

## Difficulty
Medium

## Description

Modern analytics platforms continuously process large volumes of numerical readings generated by operational systems, sensors, or application metrics. Each value represents a discrete observation captured at a specific time or index.

To ensure reliability and quality, analysts often evaluate contiguous windows of data to verify that fluctuations remain within acceptable bounds. Excessive variation inside short windows may indicate instability, noise, or anomalies requiring further investigation.

In this context, a contiguous segment of readings is considered stable when the absolute difference between any two values inside that segment remains within a tightly controlled threshold. All values within the window must collectively satisfy this bounded-variation requirement.

Your task is to analyze the entire sequence of readings and determine how many contiguous, non-empty segments satisfy the stability condition. This computation supports downstream analytics such as anomaly detection, quality monitoring, and trend validation.

## Examples  

### 1  

#### Input  
4  
5 4 2 4  

#### Output  
8  

#### Explanation  

Stable subarrays of size 1:  
[5], [4], [2], [4]  

Stable subarrays of size 2:  
[5, 4], [4, 2], [2, 4]  

Stable subarrays of size 3:  
[4, 2, 4]  

There are no stable subarrays of size 4.  

Total stable subarrays = 4 + 3 + 1 = 8  

### 2  

#### Input  
3  
1 2 3  

#### Output  
6  

#### Explanation  

Stable subarrays of size 1:  
[1], [2], [3]  

Stable subarrays of size 2:  
[1, 2], [2, 3]  

Stable subarrays of size 3:  
[1, 2, 3]  

Total stable subarrays = 3 + 2 + 1 = 6  

## Input Format  

- The first line contains an integer n — the number of elements in the array.  
- The second line contains n space-separated integers representing the array elements.  

## Output Format  

Return a single integer — the total number of stable subarrays.  

## Constraints  

1 ≤ n ≤ 100000  
1 ≤ nums[i] ≤ 10^9  

## Time Limit  

1 second  

## Memory Limit  

512 MB  

## Tags  

array, queue.
